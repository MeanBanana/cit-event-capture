# Argus Shield

Real-Time Computer Vision Application for Suspect and Vehicle Intelligence Capture in CIT Robbery Investigations.

Argus Shield is a research and development project focused on creating an investigator-facing system that uses computer vision, artificial intelligence, and data management techniques to extract, store, and query suspect and vehicle intelligence from cash-in-transit robbery footage.

The system consists of three main components:

- Android application developed using Java and Android Studio
- Python backend API responsible for communication, processing, and AI integration
- Web application developed using HTML, CSS, JavaScript, and PHP for investigator interaction

# Requirements

Before starting development, ensure the following software is installed:

- Git
- Android Studio
- Java Development Kit (JDK)
- Python 3.x
- PHP development environment
- Database management software

# Cloning the Repository

Download the repository:

```bash
git clone https://github.com/MeanBanana/cit-event-capture.git
```

Enter the project folder:


# Project Goal

The goal of Argus Shield is to create a computer vision-based intelligence application capable of assisting investigations by transforming video footage into structured, searchable suspect and vehicle information while maintaining ethical, security, and privacy considerations.
